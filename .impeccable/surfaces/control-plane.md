# Control plane surface brief

- Audience: one experienced operator managing private infrastructure.
- Job: establish a ready deployment target, then identify urgent deployment work, inspect immutable evidence, and dispatch a revision without changing context.
- Primary action: add a server on first use; deploy an application revision once the inventory chain is ready.
- First viewport: server-first readiness workspace for a new controller; permanent navigation, target context, exception-first movement board, and selected deployment dossier for a configured controller.
- Visual thesis: an operational dispatch workbench, not a generic analytics dashboard.
- Approved reference: `../mocks/dispatch-workbench.png`.
- Responsive behavior: collapse navigation first; keep movement and evidence in normal document flow on narrow screens.
- Required states: loading, server/project/application onboarding, pending server enrollment, empty deployment history, authentication, disconnected, failed, active, completed, and demo-data labeling.
