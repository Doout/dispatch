# Control plane surface brief

- Audience: one experienced operator managing private infrastructure.
- Job: identify urgent deployment work, inspect immutable evidence, and dispatch a revision without changing context.
- Primary action: deploy an application revision.
- First viewport: permanent navigation, target context, exception-first movement board, selected deployment dossier.
- Visual thesis: an operational dispatch workbench, not a generic analytics dashboard.
- Approved reference: `../mocks/dispatch-workbench.png`.
- Responsive behavior: collapse navigation first; keep movement and evidence in normal document flow on narrow screens.
- Required states: loading, empty inventory, authentication, disconnected, failed, active, completed, and demo-data labeling.
