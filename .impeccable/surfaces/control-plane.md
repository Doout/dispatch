# Control plane brief

- Audience: operators who manage private deployment targets.
- Main task: connect a target, deploy an exact revision, and inspect the result.
- First-use action: add a server.
- Normal action: deploy an application revision.
- First viewport: target status, deployments that need attention, recent results, and details for the selected deployment.
- Layout: keep navigation fixed on wide screens. Move it off canvas on narrow screens. Keep deployment details in normal document flow.
- Required states: loading, sign-in, onboarding, pending enrollment, empty history, disconnected, failed, running, and completed.
- Demo records must include a visible demo label.
